# Introduction to Python

## What is Python?

Python is a high-level, general-purpose programming language. It was created by Guido van Rossum and first released in 1991. The name comes from the comedy group *Monty Python*, not the snake.

Python is known for:

- **Readable syntax**: the code looks close to plain English, which makes it great for beginners.
- **Interpreted execution**: code runs line by line, so you can test ideas quickly without a separate compile step.
- **Dynamic typing**: you don't have to declare a variable's type; Python works it out from the value.
- **Huge standard library and ecosystem**: there is a ready-made package for almost everything.
- **Cross-platform support**: the same code runs on Windows, macOS and Linux.
- **Free and open source**, with a very large and helpful community.

## What is Python used for?

|                    Area                      |                              Examples                                   |

| Automation and scripting                     | Renaming files, scraping websites, sending emails, repetitive tasks     |
| Web development                              | Backends and APIs with Django, Flask, FastAPI                           |
| Data science and analysis                    | Cleaning, analyzing and visualizing data with pandas, NumPy, Matplotlib |
| Artificial intelligence and machine learning | TensorFlow, PyTorch, scikit-learn                                       |
| Cybersecurity                                | Port scanners, log analyzers, password and hash tools, packet analysis, 
                                                 CTF scripts, automating penetration-testing tasks                       |
| Networking and DevOps                        | Managing servers, cloud automation, configuration scripts               |
| Software testing                             | Automated tests with pytest and Selenium                                |
| Education                                    | Often the first language taught in schools and universities             |
| Game and desktop apps                        | Simple games with Pygame, GUIs with Tkinter                             |

### Why Python is popular in cybersecurity

- Quick to write: a useful script can be ready in minutes, which is handy during labs and CTFs.
- Strong libraries for networking, cryptography and web requests.
- Many well-known security tools are written in or scriptable with Python.
- Easy to read and share, so writeups and scripts are simple for others to follow.


### Helpful commands

```
python --version        # check the installed version
python script.py        # run a script
pip install requests    # install a package
```

## Related knowledge worth learning alongside Python

For cybersecurity especially:

- **Linux command line**: file system, permissions, text tools (`grep`, `cat`, `find`).
- **Networking basics**: IP addresses, ports, TCP/UDP, DNS, HTTP/HTTPS.
- **Git and GitHub**: committing, pushing, writing a good README.
- **Regular expressions (regex)**: searching and extracting patterns from text and logs.
- **Web basics**: how HTTP requests and responses work, plus HTML.
- **Cryptography basics**: hashing, encryption, encoding.
- **Problem-solving and logic**: practicing small challenges regularly.

## Practice platforms (legal and safe)

- **freeCodeCamp**: Python fundamentals.
- **OverTheWire** (Bandit, Natas): Linux and web security wargames.
- **TryHackMe** and **Hack The Box**: guided cybersecurity labs.
- **PicoCTF**: beginner-friendly CTF challenges.

> Always practice security techniques only on systems you own or in authorized lab environments.

## Summary

Python is a beginner-friendly, versatile language used everywhere from web development to AI. For cybersecurity it is one of the most valuable skills: it lets you automate tasks, build small tools and understand how existing tools work. Start with the fundamentals, practice a little every day, and document the journey on GitHub.
